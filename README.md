### Featured Work

> Some research and internship code is private due to data privacy or collaboration constraints. I summarize the core ideas and public-facing contributions here.

- **ECoG-Based Consciousness Classification**  
  Neural decoding pipeline for OAAS 1-5 consciousness-level classification with PyTorch, SLURM, LOSO transfer evaluation, and interpretable channel analysis.

- **LLM Training / Inference Memory Planning**  
  C++ scheduling algorithm for HBM-constrained Reload / Offload / Visit planning. **CCF heterogeneous computing system programming competition, Second Prize.**  
  [Code][project-hsp]

- **SysArmor / SysField Backend Integration**  
  Backend integration for enterprise endpoint protection: attack-flow parsing, playbook generation, threat detection, and baseline comparison.

- **AI Sugu - Intelligent Museum Tour Guide**  
  A WeChat mini program powered by RAG over a curated cultural-heritage knowledge base. **PKU Challenge Cup, Third Prize.**

- **Bamboo Slip Fragment Matching**  
  Contour matching with sliding-window alignment, Kabsch registration, and multi-metric scoring; improved Top-10 hit rate from **20% to 60%**.
