### 🚧 核心项目与工程实践 (Featured Projects)
> 💡 **Note on Private Repos**: 
> 由于我参与的实习与科研项目涉及**企业级网络安全架构**及**患者医疗隐私数据 (ECoG)**，核心业务代码均严格遵循保密协议存放在 Private 仓库中。
> 以下为我主导或深度参与的项目架构概述与核心贡献：

- 🛡️ **SysArmor 企业端点防护系统 (后端开发)**
  - **架构**：实现 `attack-flow解析 → Playbook生成 → SysField检测 → 基线对比` 的端到端集成流水线。
  - **贡献**：负责后端模块联调，对接攻击流解析与威胁检测链路，支撑系统评测与演示。
- 🧠 **ECoG 麻醉意识等级识别系统 (深度学习工程)**
  - **架构**：基于 64 通道 ECoG 信号，搭建 OAAS 1-5 级分类的端到端流水线。
  - **贡献**：实现坏道检测、滤波等预处理模块；对比 CNN/EEGNet/Transformer 模型（单被试平滑准确率 ~86%）；搭建 **SLURM 批量实验与可复现评测脚本**。
- 🏛️ **AI溯古 - 智能博物馆导览系统 (微信小程序)**
  - **架构**：独立搭建基于大模型 API 的 RAG（检索增强生成）流程。
  - **贡献**：负责自建知识库构建、后端逻辑与前端开发，实现有据可依的互动问答（获北大挑战杯三等奖）。
- 📜 **简牍残片边缘匹配算法 (CV算法)**
  - **架构**：设计四阶段轮廓匹配流水线（提取→归一化→几何匹配→可视化）。
  - **贡献**：实现滑动窗口对齐与 Kabsch 配准，将 Top-10 命中率由 20% 提升至 60%。
